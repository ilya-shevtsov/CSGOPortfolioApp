# CS:GO Case Portfolio Tracker

## Track your CS:GO Case investments

This is an app that allows you to track your CSGO Case Portfolio (cases you have collected or bought), track their price movement, return, and see how many cases you have and their total value.   

## With this app you will be able to:

### Real features overview

- Overview data about games cases:
	- Current market volume, lowest and mid price of the cases
	- Main information about the case:
		- Description of the case
		- Release date
	- Investing data (Monthly and daily average return, standard deviation, and sharp ratio)
- Track your investments:
	- View your hisorical Portfolio Value
	- Add cases to your portfolio

### Future full features overview

	- Current market volume, lowest and mid price of the cases
	- Main information about the case:
		- Description of the case

		- RSI finishes (NOT YET)
		- Number of drop days (NOT YET)

- Track your investments:

- You can view all the data in your preferred currency (NOT YET)

You can overview all the cases that are in the game, thier market volume, lowest and midium price.  
You can also read a brief description of the case, its release date, and its drop status.   

You can also view some analytics about the case. Its monthly and daily average return, standard deviation, and sharp ratio.  
The Portfolio screen lets you add and delete (not yet) cases, track their price movement, and their success as an investment.   

You will see the Portfolio Value history graph on the front page of the portfolio and more in-depth analysis of the portfolio by moving to the Portfolio Details screen.   
There you can view the breakdown of the portfolio by number of cases and by total value of the cases. and some other (don't know yet) things.   

You can also change the currency of the app and view all the data in the app in the currency that you prefer (not yet).
